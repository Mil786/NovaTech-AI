# NovaTech AI

Landing page moderna e responsiva para uma empresa fictícia de inteligência artificial.

O projeto foi desenvolvido com foco em praticar e aprimorar conhecimentos de desenvolvimento web utilizando tecnologias fundamentais do Front-End.

## 🚀 Tecnologias

- HTML5
- CSS3
- JavaScript
- Responsive Design
- CSS Grid
- CSS Flexbox
- CSS Animations
- Intersection Observer API

## ✨ Funcionalidades

- Landing page responsiva
- Navegação por seções
- Menu mobile
- Scroll suave
- Animações ao rolar a página
- Header dinâmico
- Cards de serviços
- Seção de estatísticas
- Depoimentos
- FAQ interativo
- Formulário de contato com validação
- Layout adaptado para dispositivos móveis

## 🎯 Objetivo

O objetivo deste projeto é praticar desenvolvimento Front-End e construir projetos reais para meu portfólio de desenvolvimento web.
